# KALEIDO Viajes — Sitio web

Sitio institucional de **KALEIDO Viajes**, agencia de viajes y turismo minorista especializada en turismo interno inclusivo para neurodiversidades (discapacidad cognitiva, intelectual y TEA).

Trabajo Final (TIF) de la Licenciatura en Turismo y Hotelería, UADE — Grupo 1.

- **Sitio publicado:** https://kaleidoviajes.github.io/
- **Instagram:** [@kaleido.viajes](https://www.instagram.com/kaleido.viajes)

## Estructura

```
index.html   Página única (HTML, CSS y JS en un solo archivo, sin dependencias de compilación)
assets/      Imágenes y logos
```

Las tipografías (League Gothic y Lexend) se cargan desde Google Fonts.

## Cómo se publica

El sitio se sirve con GitHub Pages desde la rama `main` (carpeta raíz). Cada cambio que se sube a `main` se publica solo, en uno o dos minutos.

## Identidad visual

Sigue el Manual de Marca: azul marino `#00205B`, menta `#D2E8E3` y blanco. Los colores del espectro se usan solo como detalle decorativo, nunca como color de texto. El sitio tiene modo claro y oscuro.
